# 0011-integrated-desktop-ui-vibe-architecture

## Status
accepted

## Context & Decision
为了让 CXC 桌面端应用彻底摆脱网页浏览器的感官痕迹，并具备呼吸感的高级原生桌面质感，我们决定对桌面端架构实施一体化与物理材质集成方案：

1. **原生物理视效材质**：弃用低效的纯前端大面积 `backdrop-blur` 模拟，在真实桌面端引入 Rust 原生视效插件（Windows 11 Mica/Acrylic 视效，macOS Vibrancy 视效），并在前端应用透明度自适应，由操作系统的 DWM 硬件加速完成壁纸穿透与折射。
2. **跨平台控制栏自适应**：在无边框（`decorations: false`）窗口下，根据运行平台自适应渲染窗口控制按钮（macOS 居左像素级红绿灯，Windows/Linux 居右扁平控制三键），并在 Header 绑定原生窗口控制 IPC，保证在非 macOS 平台下依旧自然。
3. **彻底屏蔽浏览器特征**：全局拦截右键默认上下文菜单、`F5`/`Ctrl+R` 快捷刷新等网页操作，对非交互文本与图像统一应用选中和拖拽保护，强制注入 Windows 原生窗口投影以防止扁平穿帮。
4. **前后台通知场景分流**：应用在前台激活状态时只使用轻量级网页 Toast 反馈；隐藏至托盘后台运行或发生异常警报时，通过系统原生 Notification 功能横幅推送给操作系统通知中心。

## Considered Options
* **完全前端 CSS 模拟**（被否决）：在桌面端无法真正穿透折射系统壁纸，且高强度模糊在低端设备上易掉帧。
* **平台强行统一样式**（被否决）：强行在 Windows 上使用 macOS 红绿灯会导致视觉风格割裂，削弱原生感。
* **保留默认浏览器行为**（被否决）：右键审查元素和误触刷新会一秒戳穿网页壳，无法获得原生体验。
