# CXC 桌面端一体化背景板设计原型方案 (Window Vibe Prototype)

为了解决**“界面视觉生硬、看着太像浏览器网页”**的问题，本项目设计并实现了**一体化窗口背景板设计 (Window Vibe Design)**，并提供了 **4 种不同质感的桌面端背景变体**与**桌面环境模拟预览系统**。

您可以通过运行桌面端，直接在页面**左下角的“一体化背景原型”浮动控制面板**中实时点击切换，对比不同方案的实际体验。

---

## 🎨 四大背景板变体方案详情

### 1. 🌐 经典网页模式 (Classic Web)
* **设计理念**: 现有的不透明网页设计，使用常规色彩填充。
* **重构细节**:
  * 保持原有的暖白 (`#f6f5f4`) 或暗黑 Notion 灰 (`#191919`) 实体背景。
  * 窗口边界采用硬性的描边线进行功能分区，适合传统的强对比文本阅读环境。

### 2. ✨ 亚克力磨砂一体化 (Acrylic Blur - 🌟 推荐)
* **设计理念**: 桌面级磨砂玻璃质感。将侧边栏、卡片和底部背景融为一体。
* **重构细节**:
  * 背景采用半透明的 `bg-background/55`，结合高饱和度的硬件加速 `backdrop-blur-[24px]`。
  * 内容卡片采用 `rgba(255, 255, 255, 0.45)` (亮色) / `rgba(26, 26, 26, 0.45)` (暗色) 半透明贴片，边缘饰以极细微的虚光投影，去除原本沉重的硬分界线。
  * 视觉效果清透、现代，随着壁纸的变化而呈现丰富的折射色彩。

### 3. 🌌 云母深空沉浸 (Mica Space)
* **设计理念**: 灵感源自 Windows 11 云母 (Mica) 材质，提供深度沉浸的静谧工作台环境。
* **重构细节**:
  * 暗色模式特化：背景采用更深邃的 `bg-[#151515]/85` 与云母磨砂，并在软件底层叠加了一层非常轻微的彩色虚光渐变（透出冷蓝与暖橘的星云光晕）。
  * 页面所有的卡片、列表背景降为极低透明度，让界面的功能模块像悬浮在星空深处，呼吸感拉满。

### 4. 🎨 极光流雾模式 (Aurora Liquid)
* **设计理念**: 充满科技感和艺术生命力的流体动态背景。
* **重构细节**:
  * 在内容窗口的最底层，注入 3 个不同大小的彩色流体光晕 (Aurora Blobs)，使用 CSS Animation 让它们在背景后进行极慢速度的旋转、漂移与变形。
  * 在流体层上覆以 `backdrop-blur-[35px]` 的重度毛玻璃网罩，形成流动的彩色云雾，让静态的配置列表仿佛置身于灵动的极光之中。

## 🖥️ 桌面环境模拟预览器 (OS Simulator)

在普通的浏览器网页中，由于缺乏真正的“操作系统桌面”作为背景，用户往往无法直接体验到“磨砂玻璃折射背景”的精美效果。为此，我们在原型中开发了**桌面环境模拟预览器**：

* **自适应检测**: 当在浏览器环境下预览本页面时，系统会默认开启**“模拟系统桌面”**。
* **独立窗口外壳**: 开启后，页面外围会展现出一个高清晰度的操作系统桌面壁纸，并将应用本身缩放到 `1024x680` 并带有 `shadow-2xl`，使其像一个真正的独立桌面 App 一样运行。
* **macOS 状态栏与控制**: 模拟了顶部的 macOS 系统菜单栏，并在 CXC Header 左侧渲染了像素级还原的 **macOS 红绿灯控制三色球 (Window Controls)**，不仅支持鼠标悬停显示图标，点击还能模拟最小化、最大化与关闭/隐藏功能（在 Tauri 环境下会调用真正的 Tauri 窗口 IPC）。
* **多款系统壁纸一键切换**: 可以在控制面板里实时切换 **枫叶极光 (Sequoia)**、**暗黑星云 (Nebula)** 和 **极简石板 (Slate)** 三款壁纸，以完美感受磨砂玻璃折射不同壁纸色彩时的惊艳视觉。

## ⚙️ 真实的桌面端一体化改造

我们同步在 `cxc-desktop/src-tauri/tauri.conf.json` 中做出了调整：
1. 开启了窗口透明 `"transparent": true`。
2. 禁用了系统原生标题栏 `"decorations": false`。
3. 当在真正的 Tauri 桌面客户端运行时，关闭控制面板中的“模拟系统桌面”，软件的亚克力和云母背景将直接折射**您电脑真实的壁纸背景**，呈现极致无缝 of 系统级融为一体设计！
