# CXC 桌面端 UI/UX 极简重构原型方案 (Prototype)

为了解决**“搜索框及以上区域占比过大，不够简洁好用”**的问题，本项目在此原型中设计并实现了 **4 种不同维度的极简 UI/UX 变体**。

您可以通过运行桌面端，直接在页面**左下角的“UI原型”控制面板**中实时点击切换，对比不同方案的实际体验。

---

## 🎨 四大 UI 变体方案详情

### 1. 🚀 双栏极窄模式 (Default)
* **设计理念**: 保留现有的“头部 Header + 搜索 Toolbar”的双栏架构，但对其进行深度视觉瘦身。
* **重构细节**:
  * Header 纵向 Padding 从 `16px` 压缩至 `10px` (`py-2.5`)，并增加了细腻的半透明毛玻璃特效。
  * Logo 大小从 `40px` 缩小至 `32px`。
  * 主标题简化为 `"CXC"`，下设 `10px` 大小的大写全称说明 `"CODE CROSS-CONNECT"`。
  * Switcher 与右侧按钮群等比例缩小，整体高度降低约 35%。

### 2. ⚡ 单栏一体模式 (Unified - 🌟 推荐)
* **设计理念**: **彻底消灭原本 Toolbar 这一整行**。将搜索、工具切换、核心操作全部合并入顶部 Header 栏。
* **重构细节**:
  * Header 纵向 Padding 进一步压缩至 `8px` (`py-2`)，使顶部操作区仅占约 `44px` 的高度。
  * 搜索框居中融合在顶部，支持 `focus` 变宽的平滑动画效果（常态 `240px`，聚焦时自动延展至 `288px`）。
  * 一键测速精简为小图标按钮，新增节点按钮在小屏幕下自动收缩为 `"Add"` 或加号。
  * **这是纵向空间利用率最高的方案，也是最符合效率工具的设计**。

### 3. 📝 Notion无界模式 (Notion)
* **设计理念**: 去除传统的“软件壳”界线，将操作栏与页面内容无缝融为一体，打造极简文档流风格。
* **重构细节**:
  * 顶部 Header 彻底隐形（无背景、无底部边框），仅保留微型的面包屑路径导航 `cxc / [Target]`。
  * 将搜索框、一键测速、添加节点、视图切换平铺在列表正上方，风格参照 Notion 数据库的操作栏设计。
  * 界面没有任何生硬的分割线，极富现代高级感。

### 4. 🔍 折叠搜索模式 (Compact)
* **设计理念**: 常态下隐藏所有搜索占位，实现主界面的极致无暇。仅在需要时唤出搜索。
* **重构细节**:
  * 默认隐藏整个搜索 Toolbar，主列表直接顶格显示，极具呼吸感。
  * 您可以点击 Header 右侧新增的 **Search 图标**，或者直接按下全局快捷键 **`Ctrl + F` / `Cmd + F`**。
  * 搜索栏将以轻微的平滑下落动画在 Header 下方展开，并自动聚焦在输入框中，再次按快捷键或失去焦点即可关闭。

---

## ⌨️ 快捷操作说明 (折叠搜索模式)
* 打开/关闭搜索: `Ctrl + F` (Windows / Linux) 或 `Cmd + F` (macOS)。
* 输入框会自动获取焦点，输入即可实时过滤节点。
